# 🤝 Come contribuire

Grazie per l'interesse verso **Appunti Python**!

Questa repository raccoglie appunti, script ed esercizi sviluppati durante le
lezioni e le sessioni di laboratorio. Prima di proporre qualsiasi cosa, è
importante conoscere le regole di seguito.

## 📄 Licenza e contributi

La repository è disponibile **solo per la consultazione** ed è distribuita sotto
la licenza riportata nel file [LICENSE](LICENSE). Per questo motivo:

- **non vengono accettate Pull Request** con modifiche, aggiunte o correzioni
  dirette ai file;
- non è consentito copiare, modificare, distribuire o creare opere derivate dai
  contenuti senza autorizzazione scritta dell'autore;
- eventuali richieste di autorizzazione vanno fatte aprendo una *Issue* o
  contattando l'autore tramite il suo profilo GitHub.

## 🐞 Segnalare un errore

Hai trovato un errore in un appunto, un refuso o un codice che non funziona?
Puoi segnalarlo aprendo una [Issue](../../issues) che contenga:

1. **Posizione**: il percorso del file (ad esempio
   `Teoria/Base/Stringhe/...`);
2. **Descrizione**: cosa non è corretto e cosa ti aspetteresti;
3. **Ambiente** (solo per gli errori nel codice): versione di Python e sistema
   operativo utilizzati;
4. **Messaggio di errore** completo, se presente.

Ogni segnalazione verrà valutata e, se corretta, la modifica sarà effettuata
direttamente dall'autore.

## 💡 Proporre un argomento

Se vuoi suggerire un argomento da aggiungere agli appunti, apri una *Issue*
descrivendo:

- l'argomento che vorresti vedere trattato;
- il tuo livello di partenza, così da poterlo collocare nel percorso corretto
  (dalle basi fino agli argomenti avanzati).

Non è garantito che ogni proposta venga accolta, ma ogni suggerimento sarà
letto con attenzione.

## ✅ Buone pratiche per le Issue

- Cerca prima tra le Issue già aperte, per evitare duplicati.
- Scrivi un titolo chiaro e una descrizione precisa.
- Apri **una Issue per ogni segnalazione**.
- Mantieni un tono rispettoso e collaborativo.

## 📚 Citare gli appunti

Se vuoi citare questa repository, usa i metadati presenti nel file
[CITATION.cff](CITATION.cff): GitHub li mostra nel pulsante
**"Cite this repository"**.
