# 🔒 Politica di sicurezza

## Natura del materiale

Questa repository contiene **appunti e script a scopo didattico**. Il codice
(in particolare quello della cartella `Client-server`) è pensato per
l'apprendimento e **non è adatto all'uso in produzione**: non implementa
autenticazione, cifratura o gestione sicura degli input.

## Segnalare un problema di sicurezza

Se ritieni di aver trovato un problema di sicurezza, ad esempio un dato
sensibile caricato per errore, puoi segnalarlo:

- tramite la funzione **Report a vulnerability** nella scheda *Security* della
  repository, se disponibile;
- oppure aprendo una [Issue](../../issues), **senza** includere dettagli
  sensibili.

La segnalazione verrà letta il prima possibile e, se corretta, il problema
sarà risolto direttamente dall'autore.

## Versioni supportate

Gli appunti vengono aggiornati continuamente: viene mantenuta solo l'ultima
versione presente nel ramo `master`.
