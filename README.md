# 🐍 Appunti Python

Questa repository contiene tutti gli appunti del linguaggio Python

## 💡 Perché nasce questa repository
Questa repository nasce per raccogliere, organizzare e condividere gli appunti
e gli script Python sviluppati durante le lezioni e le sessioni di laboratorio, 
così da avere un punto di riferimento per lo studio e il ripasso.

## 🎯 Obiettivi didattici
Attraverso questa repository si vogliono raggiungere i seguenti obiettivi:
- comprendere la sintassi di Python;
- applicare i concetti teorici visti a lezione;
- svolgere semplici esercizi;
- sviluppare semplici programmi.

## 📚 Argomenti trattati
- Basi del linguaggio e della sua sintassi;
- Stringhe;
- Strutture dati;
- Gestione dei file;
- Gestione delle eccezioni;
- Programmazione client-server.

## ⚙️ Requisiti e ambiente di esecuzione
Per eseguire i file è necessaria la versione 3.13 di Python (o successiva).
Gli ambienti di sviluppo consigliati sono Visual Studio Code e JetBrains PyCharm.

## 🚀 Come usare la repository
Per sfruttare al meglio questa repository, è consigliabile partire **sempre**
dalla teoria prima di guardare il codice e bisogna partire dal proprio livello di conoscenza
del linguaggio per poter usare al meglio questa repo.

## 🔄 Aggiornamento degli appunti
Durante e oltre l'anno scolastico, questi appunti saranno costantemente
aggiornati, in modo da permettere a chiunque di partire da qualsiasi livello,
dalle basi fino ad arrivare gradualmente ad argomenti avanzati.
